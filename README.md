# 🐧 ぺんぎん勤怠

フレックス勤務の「今月あと何時間働けばいいか」を、勤怠アプリの**スクリーンショットを選ぶだけ**で計算するWebアプリです。
スマホのブラウザで動き、ホーム画面に追加するとアプリのように開けます。無料で使えます。

## 使い方

1. 勤怠アプリの月次一覧（`9/1(火) 出勤 09:24 退勤 17:02` が並ぶ画面）をスクリーンショットで撮る
2. ぺんぎん勤怠を開いて **「📷 スクショを読み込む」** → 写真を選ぶ（何枚でもまとめて選べます）
3. 読み取り結果を確かめて **「反映する」**

これで表が埋まり、残り時間・目標との差・1日あたりの目安が自動で出ます。

- 日付の行をタップすると、出勤・退勤・休憩（5分単位）・有給・休み扱いを直せます
- 読み取りに失敗した／自信が低い行には ⚠ が付きます。反映前に時刻を直せます
- 画像が使えないときは **「📋 貼り付け」**（iPhoneの画面を長押し →「テキストをコピー」）でも取り込めます

## 計算ルール

| 項目 | 内容 |
| --- | --- |
| 所定出勤日 | 土日祝日をのぞく平日（祝日は自動判定。振替休日・国民の休日も対応） |
| 月の目標時間 | 所定出勤日 × 1日の所定時間（初期値 7時間） |
| その日の勤務時間 | 退勤 − 出勤 − 休憩（初期値 60分。5分単位で調整） |
| 有給 | 全休＝7時間 / 半休＝3時間30分 / 時間休＝1時間単位（勤務時間と合算） |
| 今月あと | 目標 − 実績（有給を入れると自動で減る） |
| フル出勤比 | 記録のある所定出勤日ごとの（勤務＋有給 − 7時間）の合計。毎日7時間働いた場合との差 |
| 1日あたりの目安 | 今月あと ÷ 今日以降で記録のない所定出勤日の数 |

会社の休業日（年末年始など）は、その日を開いて **「この日は休み扱い」** をオンにすると目標から外れます。
所定時間・休憩の初期値は「⚙︎ 設定・バックアップ」で変えられます。

## プライバシー

- スクショの文字認識は**端末の中**で行います。画像は外部に送信されません
- 記録はこの端末のブラウザ内（localStorage）にだけ保存されます。同僚と共有されることもありません
- 機種変更の前は「設定・バックアップ」でデータを書き出しておくと安心です

## 公開のしかた（GitHub Pages・無料）

同僚にもURLを教えるだけで、それぞれの端末で使えます（データは各自のスマホの中だけ）。

1. [GitHub](https://github.com/) にアカウントを作る（無料）
2. 右上の「＋」→ **New repository**。名前は `penguin-kintai` など、**Public** を選んで作成
3. 作成後の画面で **uploading an existing file** を開き、このフォルダの中身（`index.html`、`css`、`js`、`assets`、`icons`、`manifest.webmanifest`、`sw.js`）をドラッグ&ドロップ → **Commit changes**
   - `tests` と `package.json` はアップロードしなくても動きます
4. リポジトリの **Settings → Pages** → Branch を `main` / `(root)` にして **Save**
5. 1〜2分待つと `https://（ユーザー名）.github.io/penguin-kintai/` で開けます

> Public にすると誰でもURLでアプリ自体を開けますが、あなたの勤怠データが見られることはありません（データはあなたの端末の中だけ）。
> 公開せず自分だけで使いたい場合は、Netlify Drop（https://app.netlify.com/drop）にフォルダをドラッグするだけでも公開できます。

### iPhoneのホーム画面に追加

Safariでアプリを開く → 共有ボタン → **ホーム画面に追加**。

### 更新したとき

ファイルを差し替えてアップロードし直すと、アプリは次に**2回開いたとき**に最新になります（1回目は保存済みの版を表示し、裏で更新するため）。

## 補足

- 初めてスクショを読み込むときだけ、文字認識用のデータ（約8MB）をダウンロードします。次からは端末に残るので速くなります
- 文字認識には [Tesseract.js](https://github.com/naptha/tesseract.js) を使っています（jsDelivr から読み込み）
- 画像が小さすぎる（幅500px未満）と読み取れないことがあります。スクショは元の大きさのまま選んでください
- 祝日は2020年以降に対応しています。勤怠アプリの画面レイアウトが変わったときは、読み取り結果の確認画面で確かめてください

## 開発メモ

```bash
npm test          # 祝日・集計・解析ロジックのテスト（Node 20以上）
npm run serve     # http://localhost:8080 で確認
```

| ファイル | 役割 |
| --- | --- |
| `js/calc.js` | 勤務時間・有給・月の集計（純粋関数） |
| `js/holidays.js` | 日本の祝日の計算 |
| `js/parse.js` | 文字認識の結果 → 日付・出勤・退勤 |
| `js/ocr.js` | 画像の前処理と文字認識（Tesseract.js） |
| `js/store.js` | localStorage への保存・バックアップ |
| `js/season.js` / `js/mascot.js` | 月ごとの背景と舞うもの / ペンギンの表情とひとこと |
| `js/app.js` / `js/sheets.js` | 画面の組み立て / 下から出るシート類 |
| `assets/` | ペンギンと月別背景（AI生成の画像） |
